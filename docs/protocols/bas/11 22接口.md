# 机柜配置

##### 基本资料-机柜配置- 迁移设备数据 和 读取设备最新数据 的接口再调用前需要执行 GET http://localhost:8081/recover/password?password=123456 接口，password 是需要用户输入的密码，接口返回 true 才调用 迁移设备数据 和 读取设备最新数据 的接口，否则不能调用

```json
{
  "code": 200,
  "msg": "操作成功",
  // 用户是否输正确密码， true 为正确，放行
  // false 不要放行
  "data": true
}
```
