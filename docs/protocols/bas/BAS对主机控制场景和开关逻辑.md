#BAS对主机控制场景和开关逻辑

## ~~控制场景~~

BAS对主机控制某个场景，或者是控制分区开关，下发控制指令，主机接受到指令对下控制的逻辑判断如下：

1. 接收到指令前，主机应先记录所有机柜当前手、自动状态；
2. 在某个时段接收到场景控制命令（举例场景：高峰模式）后：
	1. 把当前自动状态下的机柜，切换到手动状态，并手动场景控制该机柜进入高峰模式场景；
	2. 该机柜高峰模式场景保持时间为：当前自动状态下场景的预设之间段；
	3. 达到自动状态下一个场景时间段，把之前自动切换到手动的机柜，恢复成自动模式下；
	4. 接收到高峰模式场景，当前处于手动机柜直接控制成高峰模式，进入到下一个场景时间段，保持现状；

## ~~开关控制~~

开关控制逻辑与场景控制逻辑一致，

1. 接收到指令前，主机应先记录所有机柜当前手、自动状态；
2. 在某个时段接收到开灯（广告照明区）命令后：
	1. 把当前自动状态下的机柜，切换到手动状态，并手动分区控制该机柜广告照明区开灯；
	2. 该机柜广告照明开灯保持时间为：当前自动状态下场景的预设之间段；
	3. 达到自动状态下一个场景时间段，把之前自动切换到手动的机柜，恢复成自动模式；
	4. 接收到广告照明区开灯，当前处于手动模式机柜直接控制广告照明区开灯，进入到下一个场景时间段，保持现状；

### ~~分区控制~~

主机全局分区控制和场景控，与BAS控制主机的场景模式、分区控制逻辑一样，恢复逻辑也一样。

若是分区控制，把设备切换到手动，并且是手动分组控制

举例：场景时间段01：06:00-09:30；场景时间段02：09::30-11:00
在06:20分BAS或主机全局控制“高峰模式”，主机把当前所有自动模式机柜切换成手动，然后把全部机柜手动场景“高峰模式”，并且06::20-09:30，一直保持手动场景“高峰模式”，09:30以后，把之前自动切换成手动的机柜，恢复成自动状态，手动的机柜保持手动状态。
